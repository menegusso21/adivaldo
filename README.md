# 🌿 EcoHarvest AI
> **Tecnologia que cultiva o amanhã.**

O **EcoHarvest AI** é um ecossistema de monitoramento inteligente que funde Inteligência Artificial (IA) e Internet das Coisas (IoT) para revolucionar a produtividade agrícola com impacto ambiental positivo.

---

## 📍 Objetivo Central
Nossa missão é maximizar a produção agrícola através da precisão técnica, reduzindo drasticamente o desperdício de recursos hídricos e o uso de defensivos químicos, promovendo uma agricultura de "Carbono Zero".

---

## 🛠️ A Solução Técnico-Sustentável

O projeto baseia-se em quatro pilares fundamentais de inovação:

| Tecnologia | Descrição | Impacto |
| :--- | :--- | :--- |
| **Sensores Biocompatíveis** | Dispositivos IoT que medem umidade e nutrientes em tempo real. | Decisões baseadas em dados reais. |
| **Irrigação de Precisão** | Ativação automatizada apenas onde e quando necessário. | Economia de até 60% de água. |
| **Drones Sentinelas** | Visão computacional para identificar pragas precocemente. | Redução de pulverização generalizada. |
| **Painéis Flutuantes** | Energia limpa sobre reservatórios de irrigação. | Reduz a evaporação e gera autonomia energética. |

---

## 🌿 Impacto no Meio Ambiente

* **Preservação da Biodiversidade:** Criação e monitoramento de corredores ecológicos para a fauna local.
* **Recuperação do Solo:** IA que sugere fertilizantes orgânicos e regenerativos.
* **Créditos de Carbono:** Sistema de monitoramento de sequestro de carbono para monetização da preservação.

> 💡 **Regra de Ouro:** "A tecnologia e a natureza trabalhando juntas". Não substituímos a natureza; usamos a máquina como os olhos e ouvidos da terra.

---

## 🖥️ Tecnologias Utilizadas

Este repositório contém o protótipo da interface de monitoramento, utilizando:

* **HTML5 Semântico:** Estrutura focada em acessibilidade.
* **CSS3 Moderno:** Design responsivo com animações de *Scroll Reveal*.
* **JavaScript (Vanilla):** Lógica para simulação de dados de sensores em tempo real e interatividade.
* **FontAwesome:** Iconografia técnica e intuitiva.

## 🚀 Como Executar o Projeto

1.  Clone este repositório:
    ```bash
    git clone [https://github.com/seu-usuario/ecoharvest-ai.git](https://github.com/seu-usuario/ecoharvest-ai.git)
    ```
2.  Navegue até a pasta do projeto:
    ```bash
    cd ecoharvest-ai
    ```
3.  Abra o arquivo `index.html` no seu navegador ou utilize a extensão **Live Server** no VS Code.
